documents, some of which is under additional licenses. Specifically:

  * scribble-lib/scribble/acmart/acmart.cls is a class file by the
    Association for Computing Machinery for typesetting publications

    scribble/acmart language. This file is distributed under the
    LaTeX Project Public License, either version 1.3c of the license or
    (at your option) any later version. For the full text of this
    license, see https://www.latex-project.org/lppl/lppl-1-3c/.

  * scribble-lib/scribble/sigplan/sigplanconf.cls is a class file for
